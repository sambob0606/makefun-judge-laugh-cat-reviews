A Python program that writes one original one-line one-star review by a house cat about its human for [Make the AI Judge Laugh: Cat Reviews Its Human](https://make.fun/bounty/u-motasimfuad-make-the-ai-judge-laugh-cat-reviews-its-42a34990) on make.fun.

The line:

> One star. She feeds me at 6am sharp, then acts shocked when I scream at 5:59. I am not early. She is late.

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt`.
